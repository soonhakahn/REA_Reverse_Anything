# AICE Studio — 1단계 검토 패키지

## 구현 범위
- 자체 제작 문제 은행 160문항: 기존 8단원 각각 20문항. 기존 30문항과 별개입니다.
- 객관식 80, 코드 빈칸 16, 결과 예측 48, 오류 찾기 16. 난이도 기초 54 / 응용 71 / 심화 35.
- 기존 3회(각 10문항)를 데이터 그대로 유지하고 종합 개념 모의고사 5회(각 14문항·90분) 추가.
- 종합 회차는 분석 5 / 전처리 4 / 모델링 5문항이며 공식 문항 수·시간을 참고한 자체 구성입니다. 실제 30/30/40 배점이나 실기 방식은 재현하지 않습니다.
- 단원별 정답률, 80% 미만 단원 복습 추천, 틀린 문제만 재도전.
- 날짜순 오답 노트, 동일 문항 통합, 오답 횟수, 이해함 체크, 상태별 필터, 개별·전체 재도전.
- 답안·타이머·문항 사본을 저장해 새로고침 후 이어 풀기. 새 기록에는 문항 사본을 남겨 나중에 데이터가 바뀌어도 해설 유지.
- 기존 localStorage aice-studio-v1의 done/history/attempts 보존. 이전 응시 기록의 오답도 최초 1회 이전.

## 공식 정보와 구분
2026-10-24에 실제 브라우저로 확인: https://aice.study/info/aice/asso
공식 Associate는 14문항/90분, 80점 이상 합격, 100% 파이썬 실기, Jupyter 환경, 제한적 오픈북입니다.
이 패키지의 5회는 **선택형 개념 연습**입니다. 코드 빈칸·오류 찾기도 선택형입니다. 실제 실기 재현이나 합격 예측으로 표시하지 않습니다.
군집·PCA는 공식 상세 범위에 명시되지 않아 보충 학습으로 표시하고 종합 5회에서는 제외했습니다. 단원별 은행에는 20문항을 유지했습니다.
신경망 코드 문항은 NumPy/수학을 통한 개념 계산으로 검증했으며 TensorFlow 실행 검증을 주장하지 않습니다.

## 적용 파일
기존 사이트에 덮어쓸 파일:
- site/index.html
- site/assets/app.js
- site/assets/style.css
- site/assets/exams.json
새로 추가할 파일:
- site/assets/practice-core.js
- site/assets/question-bank.json
나머지 site 파일은 공개 사이트에서 확보한 변경 없는 핵심 파일 사본입니다.
가져온 HTML의 호스팅 런타임 삽입 Cloudflare challenge 스크립트는 제외했습니다.

**이 ZIP은 전체 운영 사이트 백업이 아닙니다.** 기존 jupyter/, downloads/ 및 그 밖의 파일을 삭제하거나 대체하지 마세요. Jupyter 런타임·노트북·PDF·원본 데이터는 포함하지 않았습니다.
실제 Sites 프로젝트에는 아직 배포하지 않았습니다. 이 환경에 Sites 소스 쓰기/배포 도구가 연결되어 있지 않습니다.

## 실행과 검증
로컬 미리보기: `python3 -m http.server 8765 --directory site`
- /#exam : 기존 3회와 종합 5회, 이어 풀기 확인
- /#bank : 단원/유형/난이도 필터 → 문항 선택 → 답안 입력 → 새로고침 → 저장 확인
- /#exam/comprehensive-1 : 14문항과 90분 확인, 제출 후 단원별 분석
- /#wrong : 오답의 날짜/횟수, 이해함 체크와 필터, 재도전
- /#result/<응시기록ID> : 과거 결과와 당시 문항 유지

구조·호환성 검사: `node verification/check-core.mjs`
코드 정답 실행 검증: Python 가상환경에 verification/requirements.txt를 설치하고 `python verification/build_bank.py` 실행.
이 명령은 코드 출력 48개와 빈칸·오류 수정 32개의 정답 및 오답 선택지를 실제 실행하고, question-bank.json/exams.json을 같은 내용으로 재생성합니다. 오답의 오버플로 경고는 의도된 검증 사례입니다.
code-verification.json에 80개 코드 문항의 코드, 기대값, 관측값을 담았습니다.

## 제한
- 선택형 개념 학습이며 새로운 Jupyter 실기 회차는 이번 1단계 산출물에 포함되지 않습니다.
- 학습 기록은 해당 브라우저에만 저장합니다. 기기 간 기록 이동과 PWA는 요청 범위 밖인 4단계입니다.
- 실제 iPhone Safari에서의 기기 검증은 하지 않았습니다. 좁은 화면 Chromium 검사는 별도 보고합니다.
- 학습자료실·실습실의 대용량 원본은 기존 호스팅에서 계속 제공되어야 합니다.
- 영상 연동/플래시카드 등 2~4단계 기능은 추가하지 않았습니다.
